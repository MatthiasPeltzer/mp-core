`logoBig` / `logoSvgBig` are scalars resolved once per request by `Mpc\MpCore\DataProcessing\HeaderLogoProcessor` (see Finding #32). Replaces an inline `` block that re-ran the same language-fallback loop already done in Header.Logo.html. The flag is paired with the file's source scope (per-language vs site) so that toggling the site-level `logoSvg` switch is honoured even when the per-language YAML still carries the TCA default of `true`.
`maxHeight=920` matches the largest `.bg-svg` CSS height (see `_header.scss`: 420px on xs, 620px on sm, 920px on md+). The previous absence of `maxHeight` here meant the partial's default of 500 was used, which is fine for SVG (vector, scale-free) but produces a slightly blurry raster fallback at the md+ breakpoint.
